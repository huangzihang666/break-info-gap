# 覆盖、时效与细分检索

## 先定义可检查的覆盖

完整快报先建立矩阵，列“主题/垂类—地区—来源类型—查询与时间—状态—证据ID—下一步”。检查搜索行为和证据，不以篇幅、标题数量、搜索结果总数代替覆盖。

以下是保持广度的采编起点，目录和数量都不是范围边界；研究中可因重要新线索调整深挖分配并记录原因，不应等待用户补充关键词。既有关注方向仍记录实际状态，不静默丢弃：
1. 八个方向作为长期关注起点广扫，深挖由当期变化和证据决定，不固定每类至少两条；新主题与既有主题按同样标准评估，可优先研究或独立成篇。记录确切人群、场景或产业链环节，不将同一产品的两篇报道算两个垂类。
2. 下表补充行业全部广扫，每期至少四类下钻；连续三期累计下钻覆盖表中全部补充组。首期没有历史时先登记，不声称此前已覆盖。突发重要变化立即追加，不等轮查。
3. 国内为主，各重点板块同时检查国内与海外线索；海外确无相关可靠新增时记录结果。国家政策与地方执行、国际规则及对华影响分别设检索行。
4. 每期检查全部国内核心平台组、至少两个海外平台组；三个连续期覆盖所有列出的海外组。政策/规则与用户痛点是两种不同研究行，不能相互替代。
5. 娱乐生活与兴趣趋势为并列固定板块，按 [专门规范](entertainment-and-emerging-opportunities.md) 执行每期平台检查、各兴趣组广扫、至少四组下钻及小众线索搜索；本板块TikTok每期必查，高于普通海外轮查频率。
6. 网创项目、平台扶持/招商激励、成长型及较大项目分别设检查行，按专门规范验收；不能用短期活动取代成长机会。
7. 宏观时事、公司、报告、社媒需求、新项目、黑灰产各设横向检查行。所有栏目均可如实没有可靠新增，不能编造。

完成状态仅用：
- **已检索·有可靠新增**：有已读证据卡。
- **已检索·未发现可靠新增**：注明查询范围；不是“这个行业没发生事”。
- **仅有待核验线索**：摘要/传闻/未读正文等。
- **访问受限**：记录受限入口及尝试过的公开替代来源。
- **未检索**：记录原因，不能伪装成无新增。

覆盖概览分开统计“已完成查询”“原始正文可读”“有新增”“有待核验”；同一领域部分子项未查则保留混合状态。所有分母来自本期计划表，不称全网覆盖率。仅发出查询但结果不可用不能算完成证据核验。

## 八个参考方向的开放垂类池

以下仅为滚动起点，不是入选白名单。按当期变化选择深挖，记录其余待轮查；主动吸收无法归入现有分类的新领域、交叉方向和新观点，不要求先归类或得到用户逐项许可。

| 板块 | 可轮换下钻的方向 | 必须避免的偏差 |
|---|---|---|
| 互联网 | 内容与创作者商业化；电商/本地生活；企业SaaS与协作；搜索/广告/流量；游戏/数字内容；数据与隐私治理 | 不能只写大厂发布会，忽略商家、创作者、小企业使用变化 |
| AI | 国内外政策；基础/多模态/垂类模型；Agent及协议/工作流；应用与工具；推理部署/数据/评测；GitHub新仓库与近期走热仓库 | 新发布与上榜分列；厂商指标不等于独立评测；工具能用不等于生意成立 |
| 科技 | 半导体/算力；机器人/工业自动化；消费硬件/通信；低空/航天；新材料/先进制造；科研成果与产业化 | 论文、样机、量产、订单状态分清，不能把概念等同可交付 |
| 金融 | 货币/财政与融资；银行/支付/跨境结算；保险；资本市场与公司融资；金融科技；个体小微税费与经营资金 | 利率和适用主体核原文；企业营业收入与创业者收益不同 |
| 医疗 | 药械/审批；医保/支付；医院/基层服务；慢病/康复/心理健康；医疗IT；供应链/药店 | 不将政策解读变成诊疗建议；明确资质、地区、支付条件 |
| 养老 | 居家/社区/机构；适老化改造；护理与康复；辅具/安全设备；老人数字服务；家庭照护者支持 | 不把养老等同养老院，区分老人需求、子女付费和政府采购 |
| 单身经济 | 一人食/小份；独居安全与家务；小户型/租住；个人旅行/娱乐/社交；个体健康管理；独居人群的宠物服务 | 不能把所有宠物、青年或独居人群都认定为单身，标注样本身份 |
| 外贸 | 关税/出口管制/制裁；报关/认证/税务；跨境平台；物流/海外仓；收款/汇率；采购渠道/海外需求/本地化 | 分清原产地、目的国、品类与贸易方式，海外规则不能自动套用全国 |

AI的政策、模型、Agent、GitHub“新”和“热”还须分别设置广扫检查项，即使本期选定其他方向下钻也不能漏检。其他板块同理，用户点名事项不能仅留在候选池。

## 动态纳入新领域、新观点与新方向

开放探索贯穿选题、检索、核验和合并，不能只在八方向全部完成后象征性补一条。候选来源可包括新职业、新社区、小众消费、交叉学科、产业新环节、地方实践、海外讨论、新研究框架或新的经营方式；不要求已有热度或立刻能变现。

- **发现即登记**：记录暂定名称、原始出处、首次可核实出现/本期发现时间、具体新意、影响人群、与既有主题的关系及未知项；无法归类就先建新标签，不能塞进“其他”后不再追踪。
- **判断与分流**：影响重大且有可靠证据的线索当期优先展开；有启发但尚未验证的观点可纳入“观点/假设观察”，说明提出者、原始表述、依据、适用范围和可能反驳它的证据。传闻、营销包装和旧概念改名不能被当成已确认新趋势。
- **新观点不等于新事实**：核验其依赖的事实和数据；区分作者解释、研究假说、论证结果与编辑推断。新颖性尚未确认时仅写“本期新关注”，不声称首次提出。不同解释按证据质量呈现，不能为求新奇制造对立。
- **及时扩展**：当期即可新增专题、调整研究角色与检索词，不等固定轮查结束。重要探索可优先于机械配额；保留被推迟的事项及补查安排，不事后删去未完成计划来伪造全面。
- **持续追踪**：用稳定主题ID记录“候选/持续追踪/独立专题/合并/暂缓及原因”；将有用入口加入信息源导航，重要线索写回机会观察表或待核验清单。不是每条新观点都必须包装为项目。
- **滚动更新目录**：每期复盘新加入、扩展、更名或合并的主题及证据。复查需求增长、独立来源、实际应用和反例；不能仅因不属于八方向而排除，也不为维持旧目录压低新领域优先级。

三个层次贯穿整期：宏观政策/时事 → 行业/公司变化 → 具体人群在具体场景的任务、费用或障碍。每个下钻条目至少说明“谁＋什么场景＋什么变化/问题”，并尽可能追到产业链环节、城市/地区、渠道和付费方。

## 政策、时事与公司

- 国内：中央政策、部门实施细则、地方落地分别检索；财政税收、就业社保、市场准入、消费、产业、金融、数据与互联网、民生、进出口等不能只盯补贴。
- 海外：重点贸易伙伴/相关市场的关税、出口管制、数据隐私、AI、平台、移民用工、税务与贸易规则；优先查美欧及亚洲相关市场，按事件扩展，不固定只有美欧。
- 时事：经济数据、消费与就业、地缘事件、供应链扰动、公共事件等；只做有来源的影响分析，不强行推演每件时事都能赚钱。
- 公司：每期筛代表性龙头、挑战者及细分企业，维护轮查记录；产品、融资并购、渠道、合作、价格、经营与退出均可。融资到账/意向、裁员传闻/确认、签约/实际订单分开。
- 行业报告：新发布报告、有效数据更新、细分调查分别搜索。新发布但统计期旧，仍可列报告栏目并显示统计期，不能宣称反映当前实时行情。
- 单篇公司宣传不代表行业趋势；“趋势”至少说明时间序列或多主体证据，否则写为单一信号。

## 平台与社媒：不能只查容易访问的平台

国内核心组，每期逐组检查其主要成员的公开新规/活动与问题线索；组内未查的平台单独标明：
1. 抖音、快手。
2. 微信生态：视频号、公众号、小店等。
3. 小红书。
4. B站。
5. 微博、知乎、百度内容与流量生态。
6. 淘宝/天猫、京东、拼多多、1688。
7. 闲鱼、美团等交易/本地生活平台。

海外轮查组：
1. TikTok。
2. YouTube。
3. Instagram、Facebook等Meta平台。
4. X、Reddit等讨论平台。
5. Amazon、Shopify、Etsy等电商与商家工具。

V2EX、即刻、行业论坛、公开问答、应用商店评论、公开投诉入口等补充细分需求。不能用V2EX/Reddit两站替代中国大众平台覆盖；热榜和二手采访不能冒充原始评论。其他有价值平台随发现加入。

检索路径分开：
- 官方新闻室/规则中心/创作者与商家公告 → 正文附件 → 生效与适用条件。
- 原帖/评论/用户评价 → 具体问题与日期 → 独立用户 → 既有替代方案 → 付费线索。

无法访问登录墙或评论正文，记录实际限制；尝试官方公开入口、公开索引、可信报道或其他独立讨论，并注明间接证据。不要编造原帖、绕过权限或为了截图数量灌水。

## 搜索方法与时效关口

1. 宽搜组合：领域/主体＋时间范围＋发布/修订/上线/成交/停服/下架/涨价等动作；并查原文入口，不能只依赖搜索日期排序。
2. 下钻组合：人群/业务角色＋场景/环节＋问题词，例如“太贵、找不到、手工、退款、迁移、兼容、缺货、求推荐、愿付费”。同时用中英文及必要的当地术语检索。
3. 机会组合：新服务/新产品/客户案例/实际收费/订单/需求招募/平台活动等；不只搜索“赚钱项目”。主动识别卖课、招商、返佣和收入截图营销。
4. 最近24小时重点快扫、主窗口系统搜索、历史背景补读分别记录，不能把“搜索了最近24小时”当成所有结果都在24小时内。
5. 政策检查官网原文与附件；公司查官方公告/交易所披露；AI查官方发布、论文、仓库releases/commits/license；报告查发布方与方法；社媒回到原帖。
6. 收束前检索本期主要主体的更新/撤回/澄清，重查关键机会开放状态。拿不到实时名额、利润或动态状态，直接写未知。
7. 同一事件多来源合并为一个事件ID；不同事件即便同一主体仍分开。实质修订保留前后差异，纯网页维护不算新规。
8. 对已知有重大突发而尚未取证的事项专门标记并补查，不能在“关键变化”中遗漏而静默收工。

## 来源导航的长期积累

现有导航是入口，不是最新结论。逐期扩展官方监管/地方部门、公司公告、研究机构、仓库、平台规则与真实讨论入口；每项标明用途、地区、语言、最近实际访问日期、正文/摘要/受限状态。候选入口与已使用证据分开，不伪造链接或访问记录。

输出导航让用户能继续自己查；记录盲区和待补来源，比罗列大量重复主页更有用。
